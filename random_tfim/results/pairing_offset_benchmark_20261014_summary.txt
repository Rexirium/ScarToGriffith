CONCLUSION
Full pairing removes negative subtraction artifacts in tested samples and greatly improves most tails, but 3 strong-FM reference cases still fail 1e-8 relative accuracy.
Worst pairing relative error is about 6.18e12: positivity is not an accuracy certificate.
Hybrid agrees with full pairing to 1.78e-15 in these reference cases; this is empirical and does not replace its truncation bound.
Runtime depends strongly on field and whether the current code falls back to its Pfaffian; memory allocations increase.
Zero-overlap states need a different reference chart or a separate fallback before production replacement.
Real time, peak RSS, all 101 production fields and 50000 realizations per field were not tested.
