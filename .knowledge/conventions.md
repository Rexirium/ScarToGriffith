# 跨项目约定

- 随机/纯净 TFIM、PXP 使用 Pauli 矩阵；某些独立基准使用 S=σ/2。换写自旋乘积时双线性项差 4 倍、单站点场差 2 倍，参数必须随算符一起换。
- TFIM 两个当前实现都是 OBC；PXP 是 PBC；经典 random_ising 为二维方格 PBC。独立 oracle 可用不同边界，不能直接拿总能量或有限尺寸能隙互比。
- 量子时间取 ħ=1；经典温度取 kB=1。热浴 sweep 不是量子实时间，虚时间 τ 也不是实验松弛时间。
- 纠缠熵用自然对数；每格点量、总量以及均值/典型值不得混用。先取 log 再无序平均与先平均再取 log 不同。
- TFIM 的 offset 扣最低奇宇称跃迁；PXP connected 关联扣热平均平方；经典固定起点交叠未做 connected 减项。
- 基矢/张量的物理腿次序、bit→site、sector、初态、时间/能量单位均以 [对应项目卡](README.md) 为准；新增 TN/线路实现须明确映射到同一约定后再比数据。
