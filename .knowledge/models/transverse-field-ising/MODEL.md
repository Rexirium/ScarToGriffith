# 横场 Ising：项目分派

共同哈密顿量 `H=−Σ J_i σz_i σz_(i+1)−Σ h_i σx_i`，使用 Pauli；当前两套实现都为 OBC。

- 随机键/随机或固定横场、能隙、空间/时间关联、熵 → [random_tfim 项目卡](../../projects/random_tfim.md)。
- J=1、物理横场 h 的纯净虚时减项对照 → [tfim 项目卡](../../projects/tfim.md)。
- 独立均匀 PBC 能量基准 → [tfim-chain](../../solvable/tfim-chain/ORACLE.md)，不替代 OBC 测试。
- 背景原文 → [Dutta 等综述](1012.0653_quantum-phase-transitions-in-transverse-field-spin-models-fr.md)。

二维经典 random_ising 不是横场量子模型；见 [其项目卡](../../projects/random_ising.md)。
