# LTRG / XTRG

用 MPO 表示热密度矩阵；LTRG 小虚时步推进，XTRG 反复平方使 β 加倍。保存每次重归一化的因子，才能恢复自由能。

验证与限制：增加 MPO 键维并检查起始 β/步长；对能量、熵、热容及低温尾部独立验收。双层收缩与单层表示的截断方式不同，不能只比较同一个 χ。
